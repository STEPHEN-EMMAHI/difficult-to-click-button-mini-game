## How to clone difficult to click button mini game

1. Clone repo
   ```
   git clone git@github.com:STEPHEN-EMMAHI/difficult-to-click-button-mini-game.git
   ```
2. Install dependencies
   ```
   npm install
   ```
3. Run development Environment
   ```
   npm run dev
   ```
4. Copy local host and send to broqwser <br>
   Example: http://localhost:123
